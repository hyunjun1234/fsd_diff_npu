1단계(구현 계획 4.2절) Hailo-8 단독 실기 검증의 첫 부분입니다. 0단계 점검 결과는 out/measure/00_env_check.md 에 있으니 먼저 읽으세요.

현재 사실:
- 파이 카메라는 계획(Camera Module 3 Wide 2대)과 다릅니다. 0번 ov5647(2592x1944, 일반 화각으로 추정), 1번 imx708(rpicam 이름이 imx708_wide 가 아니므로 일반 Camera Module 3, 수평 약 66도로 추정, Rotation 180). 카메라 교체 여부는 사람이 정합니다. 지금은 있는 카메라로 진행합니다.
- 파이의 /usr/share/hailo-models/yolov8s_h8.hef 가 동작하고 hailortcli run 으로 284 FPS 였습니다.
- 맥에서 테스트는 /usr/bin/python3 -m pytest -q 로 돌립니다(에이전트 가상환경에는 pytest 가 없습니다).

할 일:
1. 파이 models/ 에 yolov8s_h8.hef 를 복사하고(cp, sudo 불필요), 설정이 그 경로를 찾게 합니다.
2. 실제 카메라 구성에 맞는 설정 파일 configs/two_cam_current.yaml 을 새로 만듭니다. 0번 ov5647 을 전방, 1번 imx708 을 후방으로 두고, 내부 파라미터는 센서 데이터시트의 화소 크기와 렌즈 초점거리에서 계산한 근사값을 넣되 주석에 "보정 전 근사값"과 계산 근거를 적습니다. 장착 높이와 각도는 기존 two_cam.yaml 값을 그대로 쓰고 주석에 "실측 필요"라고 적습니다. imx708 Rotation 180 을 소스나 설정에서 처리합니다.
3. PiCameraSource.close() 가 stop() 만 불러 카메라를 놓지 않는 문제를 고치고(close 도 부르기), 카메라 해상도와 모드 선택이 위 두 센서에서 동작하게 합니다.
4. 실제 카메라 2대 + Hailo-8 로 scripts/run_demo.py 를 headless 로 300프레임 이상(timeout 180초) 돌립니다. 카메라 앞에 사람이나 물체가 없을 수 있으니, 검출이 0개여도 실패로 보지 말고, 대신 카메라 한 프레임을 저장해 HailoBackend 에 넣어 parse_hailo_nms 의 좌표 순서와 정규화가 맞는지(박스를 원본 이미지에 그려 out/measure/01_det_check_cam0.png, cam1.png 저장) 확인합니다. 저장소에 사람이나 차가 찍힌 샘플 이미지가 없다면 /usr/share 아래 hailo 예제 이미지나 rpicam 스틸로 대신합니다.
5. 단계별 처리 시간을 잽니다. 카메라 획득, 전처리, Hailo 추론, NMS 파싱, 지면 투영(IPM), 병합, 추적, BEV 합성, 렌더링 각각의 평균, p50, p95 ms 와 전체 FPS. 측정 코드는 파이프라인에 켜고 끌 수 있는 타이머로 넣습니다(기본 꺼짐, --profile 같은 옵션). 같은 측정 중 vcgencmd get_throttled 와 온도를 시작과 끝에 기록합니다.
6. 10 FPS 목표(카메라 2대)에 못 미치면 계획 3.3절의 대응(BEV 해상도 0.1m, 바닥 영상 합성 끄기, 렌더링 스레드 분리) 중 효과가 큰 것을 실제로 적용해 전후 수치를 비교합니다. 설정 옵션으로 넣고 기본 동작은 바꾸지 않아도 됩니다.
7. 새 코드에는 테스트를 더하고 맥과 파이 양쪽에서 pytest 를 통과시킵니다.

결과 문서는 out/measure/01_stage1_hailo.md 에 씁니다. 첫 문장은 "이 문서는 ~입니다"로 시작하고, 쉬운 존댓말, 이모지와 가운뎃점(·)과 긴 줄표 없이, 표는 3열 이하로 하고 수치에는 조건(카메라, 해상도, 프레임 수)을 붙입니다. 확인 못 한 것은 "확인 필요"로 적습니다.

규칙: 코드는 파일 맨 위 설명 블록 없이 바로 시작하고 역할별로 구획을 나누며 쉽고 꼼꼼한 주석을 답니다. git commit, push, sudo 금지. 카메라와 NPU 를 쓰는 명령에는 timeout 을 붙입니다.

마지막 답에는 바뀐 파일, 테스트 결과, 단계별 시간 표 요약, 10 FPS 달성 여부, 그리고 사람이 해야 할 일(체커보드 보정, 카메라 장착 높이와 각도 실측 등)을 따로 적어 주세요.
